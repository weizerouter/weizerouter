# Contributing

This repository contains public documentation for the Weize Studio / WeizeRouter ecosystem, not production source.

Documentation corrections, broken-link reports and sanitized integration examples are welcome through Issues or pull requests. Use the live product catalog and checkout as sources for current offers. Do not invent model capacity, uptime, pricing or delivery guarantees.

Never commit credentials, `.env`, customer data, private logs, internal infrastructure details or private portal links. Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
